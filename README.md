# ADC Example for Agafia SG0+

This project demonstrates how to read **analog input** from **Pin A0 (PA0)** and display the result on a **serial terminal**.

## Hardware Requirements

To run this example, you will need:
- **Agafia SG0+** development board
- **Analog sensor/potentiometer** (to provide variable voltage input)
- **USB cable** (for programming and serial communication)
- **Computer with a serial terminal application** (e.g., PuTTY, CoolTerm, Arduino Serial Monitor)

## Pin Configuration

| Function | Pin |
|----------|----|
| ADC Input | PA0 (A0) |
| Serial Communication | USB (UART) |

## Installation & Usage

1. **Connect the analog sensor** to **Pin A0 (PA0)**.
2. **Upload the provided ADC example code** to the Agafia SG0+ board.
3. **Open a serial terminal** on your computer and set the baud rate to **115200**.
4. **Observe the ADC readings** being displayed live.
